購買說明

🧸 我們是誰

四郎玩具箱是日本代購小店，會不定時開放日本限時連線，幫大家買扭蛋、寶可夢、三麗鷗、戰鬥陀螺、松本清藥妝、唐吉訶德、二手店挖寶、日本限定與機場限定商品等，也有現貨和預購商品等服務。

🛒 怎麼購買

  1. 使用 LINE 登入四郎玩具箱
  2. 到「商品」挑選想要的商品，進入商品頁加入喊單
  3. 到「喊單」查看訂單紀錄與狀態：待確認 → 已確認
  4. 結單：現貨／預購自第一筆喊單起 3 天內（第 3 天 24:00 前）結單；限時連線在專區關閉後 3 天內結單
  5. 送出結單後 3 天內（第 3 天 24:00 前）完成匯款

喊單即視同同意購買，請確認商品及需求後再喊單，請勿棄單。

📋 待確認／已確認

限時連線商品依喊單順序於當地採購，成功購買後會更新為「已確認」。若數量不足，未購得的訂單會顯示「缺貨已幫您取消」，已付訂金全額退還。

訂單顯示「已確認」後即代表訂單成立，恕不接受任意更改或取消。如對商品、付款方式或訂單內容有任何疑問，請於喊單前或訂單仍為「待確認」時提出。

💰 訂金

限時連線商品，同一件商品喊單金額合計滿 NT$1,000（含）需先付 50% 訂金。現貨和預購不用付訂金。

📦 運費與出貨

  • 7-11／全家：NT$60
  • 黑貓宅急便：NT$130

每筆結單各自計算運費，不與前後訂單合併計算或寄送；每個限時連線專區的結單也各自計算。

預購商品會等該筆訂單的商品全部到齊後，再統一安排寄出；完成付款不代表立即出貨。

↩️ 退換貨

代購商品除商品本身有重大瑕疵外，恕不接受個人因素退換貨，例如：實品與想像不符、尺寸／顏色不喜歡、臨時改變心意等。

訂單成立後恕不接受因個人因素要求更改或取消。

⏰ 逾期未結單／未付款

超過結單期限仍未結單，請立即私訊官方 LINE 說明原因；未說明者將視同棄單。

逾期未付款將視同棄單並取消訂單，如已支付訂金，訂金恕不退還。

棄單者將清空優惠券、移出社群並永久封鎖，恕不再開放加入。
